# 📌 سیستم مدیریت و یادآور هوشمند اقساط و چک (قسط و چک)

یک اپلیکیشن اندرویدی مدرن، توسعه‌یافته با **Jetpack Compose** و **Kotlin** برای مدیریت کامل و هوشمند سررسید اقساط ماهیانه و چک‌های بانکی صادره/وارده با سیستم یادآوری پیشرفته چندمرحله‌ای.

---

## 🚀 ویژگی‌های کلیدی اپلیکیشن

1. **پایگاه داده آفلاین امن (Room)**: ذخیره امن تمام اقساط و چک‌ها به صورت محلی با ایندکس‌های بهینه‌سازی شده.
2. **سیستم هشدار پیشرفته**:
   - زمان‌بندی یادآورها در چند مرحله پیش از سررسید.
   - لغو و ساخت مجدد دقیق آلارم‌ها هنگام ویرایش داده‌ها جهت جلوگیری از هشدارهای ناخواسته.
3. **بازنشانی خودکار (BootReceiver)**: فعال‌سازی مجدد کامل هشدارها پس از روشن شدن (ریاستارت) گوشی با استفاده از استاندارد `goAsync()`.
4. **داشبورد تحلیلی مدرن**:
   - وضعیت پرداخت‌ها، نمایش پیشرفت و لیست اقساط و چک‌های نزدیک.
5. **خروجی گرفتن، مهاجرت داده‌ها و بک‌آپ گیری (Backup & Sync)**:
   - پشتیبان‌گیری استاندارد JSON با قابلیت بازگردانی (Restore) دقیق داده‌ها به همراه تمام فیلدهای سفارشی.
   - خروجی اکسل (CSV) استاندارد.
6. **امنیت**: قابلیت تعیین پین‌کد (PIN) اختصاصی.

---

## 🛠️ ساختار لایه‌ای پایگاه داده و مهاجرت‌ها (Migrations)

اپلیکیشن از سیستم مهاجرت ساختاریافته بدون از دست رفتن داده‌های کاربر پشتیبانی می‌کند:
- **مهاجرت ۱ به ۲**: ایجاد شاخص‌ها (Indexes) روی فیلدهای پرکاربرد.
- **مهاجرت ۲ به ۳**: افزودن فیلد تصویر (`imageUri`) و وضعیت برگشتی چک‌ها (`isBounced`).
- **مهاجرت ۳ به ۴**: افزایش بازدهی با افزودن ایندکس روی مبالغ، شماره چک و دریافت‌کننده جهت لود بهینه.

## 🏗️ نحوه بیلد و اجرای پروژه

### 🔹 بیلد نسخه دیباگ (Debug)
برای بیلد سریع نسخه آزمایشی، در ترمینال دستور زیر را اجرا کنید:
```bash
./gradlew clean
./gradlew assembleDebug
```
(یا به جای `./gradlew` از `gradle` در محیط‌های کانتینری استفاده کنید.)

### 🔸 بیلد نسخه انتشار (Release) با امنیت بالا
در نسخه جدید، بیلد Release کاملاً ایمن است. شما **نمی‌توانید** بدون متغیرهای معتبرِ کلیدِ امضا نسخه‌ی انتشار بسازید. در صورت عدم تنظیم متغیرها، پروسه‌ی بیلد با پیام خطای مشخص متوقف می‌شود.

شما باید متغیرهای زیر را در سیستم عامل یا CI/CD خود تعریف کنید:

- `SIGNING_STORE_FILE` (آدرس دقیق فایل `.jks` یا `.keystore`)
- `SIGNING_STORE_PASSWORD`
- `SIGNING_KEY_ALIAS`
- `SIGNING_KEY_PASSWORD`

پس از تنظیم متغیرها، می‌توانید خروجی `APK` یا `AAB` بگیرید:
```bash
./gradlew assembleRelease
./gradlew bundleRelease
```
