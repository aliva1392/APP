# 📌 سیستم مدیریت و یادآور هوشمند اقساط و چک (قسط و چک)

یک اپلیکیشن اندرویدی مدرن، توسعه‌یافته با **Jetpack Compose** و **Kotlin** برای مدیریت کامل و هوشمند سررسید اقساط ماهیانه و چک‌های بانکی صادره/وارده با سیستم یادآوری پیشرفته چندمرحله‌ای.

---

## 🚀 ویژگی‌های کلیدی اپلیکیشن

1. **پایگاه داده آفلاین امن (Room)**: ذخیره امن تمام اقساط و چک‌ها به صورت محلی با ایندکس‌های بهینه‌سازی شده برای جستجو و مرتب‌سازی سریع.
2. **سیستم هشدار پیشرفته و تکرارناپذیر**:
   - زمان‌بندی یادآورها در چهار مرحله حیاتی: **۷ روز مانده**، **۳ روز مانده**، **۱ روز مانده (فردا)** و **روز سررسید**.
   - بازنویسی کاملاً هوشمند آلارم‌ها هنگام ویرایش یا ثبت مجدد جهت جلوگیری از هشدارهای تکراری.
3. **بازنشانی خودکار هشدارها پس از راه‌اندازی مجدد گوشی (BootReceiver)**: فعال‌سازی مجدد کامل هشدار اقساط تکمیل‌نشده و چک‌های پاس‌نشده به محض روشن شدن گوشی.
4. **داشبورد تحلیلی مدرن**:
   - نمایش نزدیک‌ترین سررسیدهای مالی به صورت ویجت اعلان دائم (Ongoing Notification).
   - نمایش نمودار پیشرفت پرداخت‌ها و خلاصه‌ای از کل تعهدات مالی.
5. **خروجی گرفتن و مهاجرت داده‌ها (Backup & Sync)**:
   - خروجی استاندارد JSON برای مهاجرت داده‌ها بین دستگاه‌ها.
   - گزارش‌گیری اکسل (CSV) با کدگذاری UTF-8 BOM جهت نمایش بدون نقص متون فارسی در مایکروسافت اکسل.
   - گزارش متنی خلاصه و شکیل برای اشتراک‌گذاری در پیام‌رسان‌ها.
6. **امنیت پیشرفته**: امکان فعال‌سازی پین‌کد امنیتی (PIN) برای جلوگیری از دسترسی‌های غیرمجاز.

---

## 🛠️ ساختار لایه‌ای پایگاه داده و مهاجرت‌ها (Migrations)

اپلیکیشن از سیستم مهاجرت ساختاریافته بدون از دست رفتن داده‌های کاربر پشتیبانی می‌کند:
- **مهاجرت ۱ به ۲**: ایجاد شاخص‌ها (Indexes) روی فیلدهای پرکاربرد نظیر تاریخ سررسید و وضعیت پرداخت.
- **مهاجرت ۲ به ۳**: افزودن فیلد پیوست تصویر (`imageUri`) به اقساط و چک‌ها و وضعیت برگشتی چک‌ها (`isBounced`).
- **مهاجرت ۳ به ۴**: افزایش بازدهی با افزودن ایندکس روی مبالغ، شماره چک و نام دریافت‌کننده جهت لود بهینه لیست‌های مالی حجیم.

## 🏗️ راهنمای پیکربندی و بیلد گرفتن

### بیلد نسخه Debug
برای اجرای بیلد معمول و ساده برنامه:
```bash
gradle :app:assembleDebug
```

### بیلد نسخه Release (رسمی)
اپلیکیشن برای تولید امن نسخه Release با متغیرهای محیطی ساین می‌شود. برای بیلد نسخه انتشار (AAB) دستور زیر را اجرا کنید:
```bash
gradle :app:bundleRelease
```
همچنین برای تولید فایل APK رسمی می‌توانید از `gradle :app:assembleRelease` استفاده کنید.

**نحوه ساین و متغیرهای محیطی:**
برای گرفتن بیلد Release موفق، متغیرهای سیستم عامل خود را قبل از بیلد ست کنید:

| نام متغیر محیطی | توضیحات |
|---|---|
| `KEYSTORE_PATH` | مسیر فایل کلید دیجیتال (`.jks`) |
| `STORE_PASSWORD` | رمز عبور Keystore |
| `KEY_PASSWORD` | رمز عبور اختصاصی کلید امضا |

> ⚠️ **توجه امنیتی**: در نبود متغیرها و فایل Keystore، پروسه بیلد `Release` با خطا متوقف می‌شود (Fallback به کلید Debug نمی‌کند) تا کاربر به اشتباه نسخه دولوپ را انتشار ندهد.

## 🧪 تست‌های خودکار و تست مهاجرت

پروژه مجهز به تست‌های واحد و مهاجرت دقیق با **Robolectric** است. برای اجرای تست‌ها دستور زیر را اجرا کنید:

```bash
gradle :app:testDebugUnitTest
```
